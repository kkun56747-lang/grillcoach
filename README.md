# grillcoach

自适应需求探索、独立决策与动态行动教练。

这是完整的 **grillcoach 3.0** 单文件 Skill，基于原 **Butler Intent & Action Coach 3.0** 演进。原始内容保留，正式 Skill 标识改为 `grillcoach`。

## 核心功能

- 按场景自动决定直接行动、快速澄清、深度探索、反方审查、策略规划、执行调整或复盘
- 用竞争性假设与高价值问题澄清需求，而不是无限提问
- 区分事实、用户自述、假设和未知，不臆断心理或捏造证据
- 审查错误前提、目标冲突、工时缺口、机会成本和替代方案
- 输出可验证、可执行的行动建议，并允许中途修改

## 安装

将 [SKILL.md](./SKILL.md) 保存到 Agent 的 Skill 目录中，例如 `~/.agents/skills/grillcoach/SKILL.md`。不同客户端的 Skill 发现与调用方式可能不同。

**源文件**：`Butler-Intent-Action-Coach-v3-complete.txt`。此仓库上传时仅变更 frontmatter 中的 `name` 与正文标题，原规则未删改。
